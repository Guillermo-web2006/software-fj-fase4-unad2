# Software FJ – Fase 4 UNAD

Proyecto académico de Programación (213023). Sistema en Python sin bases de datos, con clientes, servicios, reservas y registro de errores.

## Ejecutar

```bash
python main.py
python -m unittest -v pruebas_clientes.py
```

## Archivos y aportes

- `cliente.py`, `pruebas_clientes.py`: módulo inicial de clientes y sus pruebas, aporte de Guillermo Enrique Santacoloma López.
- `servicios_y_excepciones.py`: servicios especializados, excepciones y logging, aporte facilitado por Keila Marytza Mosquera Ramírez.
- `reserva.py`, `main.py`: integración y demostración adicional preparada para completar el proyecto; atribuir a quien efectivamente incorpore y pruebe estos archivos.
- `software_fj.log`: archivo de registro; se amplía al ejecutar el programa.

El sistema usa datos ficticios de demostración.
